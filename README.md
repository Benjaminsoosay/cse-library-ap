# Library Management API

A comprehensive REST API for managing books and authors in a library system, built with Node.js, Express, and MongoDB.

## Features

- *CRUD Operations*: Full Create, Read, Update, Delete functionality for Books and Authors
- *Data Validation*: Comprehensive validation for all input data
- *Error Handling*: Robust error handling with appropriate HTTP status codes
- *API Documentation*: Interactive Swagger/OpenAPI documentation
- *MongoDB Integration*: MongoDB with Mongoose ODM
- *Security*: Helmet.js for security headers, CORS enabled
- *Pagination*: Support for paginated results
- *Search & Filter*: Filter books by genre, availability, and author

## Tech Stack

- *Runtime*: Node.js
- *Framework*: Express.js
- *Database*: MongoDB with Mongoose
- *Documentation*: Swagger/OpenAPI
- *Security*: Helmet, CORS
- *Environment Management*: dotenv
